# Incoming pages

Put pages saved from Cardmarket here (Firefox: Ctrl+S → "Web Page, HTML only").
Name them so it's clear what they are, e.g. `cart.html`, `seller-list.html`,
`seller-table.html`.

Everything in this folder except this README is ignored by git, because saved
pages can contain personal data (name, address, username, e-mail, order
numbers). Claude checks and cleans each page before a copy goes into
`test/fixtures/`. Delete the raw files here once they're no longer needed.
